# Acropolis Quest

A kid-friendly walking guide to the Acropolis of Athens. It has a to-scale map, a GPS "you are here" dot, and 9 stops. Each stop has a story, a detective challenge and a riddle that earns a star.

Open `index.html` over HTTPS (for example with GitHub Pages) so the browser can use GPS. If GPS isn't available, tap **I'm here** and then tap the map.
